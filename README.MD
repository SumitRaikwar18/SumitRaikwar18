### 🌊 Limnora

**Freshwater Evidence & Human Review Platform**

Built for the **OneAquaHealth IEEE Global Hackathon 2026**.

Limnora turns uncertain freshwater citizen observations into traceable evidence.

The AI screens each image independently — without seeing the observer's category first.

When the observer and AI disagree, Limnora does not silently choose a winner.

Instead it keeps the disagreement visible and asks:

> **What evidence should we collect next?**

**Highlights**

- Independent image-first AI screening
- Observer vs AI evidence comparison
- Human review without overwriting original records
- Focused revisit questions
- Reviewer Workbench
- Researcher evidence handoff
- Privacy-preserving image processing
- Graceful AI failure handling

`Next.js` `TypeScript` `Supabase` `OpenRouter` `OpenStreetMap` `Sharp`

# 🧠 What I Like Building

### Human-in-the-loop AI

I don't want the model to silently become the authority.

I prefer workflows like:

```text
User evidence
     ↓
Independent AI interpretation
     ↓
Compare / verify
     ↓
Human judgment
     ↓
Next action
```

Limnora is an example of this approach.

---

### Reliable AI workflows

Model calls can fail.

Providers can rate-limit.

Users can provide incomplete information.

Two interpretations can disagree.

The system still needs to behave correctly.

I care about:

```text
failure recovery
provenance
structured outputs
human review
immutable source data
clear trust boundaries
```

---

### Agent tools

I'm interested in AI systems that can **do useful work through tools**, not just generate text.

That includes:

- MCP tools
- API integrations
- structured actions
- external services
- programmable payments
- verifiable execution

PayWall.ai explores this from the payments side.
